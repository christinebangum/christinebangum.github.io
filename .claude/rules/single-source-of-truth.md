# Single Source of Truth: Paper Workflow

**The Overleaf `.tex` file is the authoritative source for the paper text.** The local copy is for Claude review only.

## The SSOT Chain

```
Overleaf main.tex (SOURCE OF TRUTH for paper text)
  ├── Local .tex copy (derived — for Claude review/proofreading)
  ├── *.bib (bibliography — shared between Overleaf and repo)
  └── output/ (tables + figures — generated by Stata, included in LaTeX)

Stata .do files (SOURCE OF TRUTH for empirical analysis)
  ├── output/tables/*.tex (derived — generated by Stata)
  └── output/figures/*.pdf (derived — generated by Stata)
```

## Key Rules

1. **Never edit the local .tex and assume it will sync back to Overleaf** without Christine's explicit instruction
2. **Tables and figures are generated by Stata** — never hand-edit output files
3. **Bibliography** may be edited locally or on Overleaf — coordinate with Christine on which is canonical
4. **Proofreading changes** should be presented as a report, not applied directly to the .tex

## Overleaf Sync Protocol

When working with the local .tex copy:
1. **Read** the .tex to understand current paper state
2. **Proofread** and produce a report of suggested changes
3. **Present** changes to Christine for approval
4. **Christine applies** approved changes on Overleaf (or instructs Claude to edit locally)

## Stata Output Protocol

When generating tables or figures:
1. Stata .do files produce output to `output/tables/` and `output/figures/`
2. LaTeX paper includes these via `\input{output/tables/table_name.tex}` or `\includegraphics{output/figures/figure_name.pdf}`
3. If a table/figure changes, re-run the relevant Stata script — never hand-edit the output
